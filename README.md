# Cierre en Sitio – Prototipo v0.1

Página web estática (HTML/CSS/JS, sin dependencias) para la Actividad 3 "Construir y probar el concepto".
Registra cotas por muro, valida el cierre dimensional, vincula fotos a cada muro y muestra el % de completitud del recinto.

Los datos se guardan en el navegador del dispositivo (localStorage).
